# scenes/ — сцены, ОТДЕЛЬНО от движка и объектов

Сцена — павильон: свет, окружение для отражений, фон, экспозиция. Ничего не знает о том,
какой объект в ней стоит. Какую сцену использовать — решает объект (`manifest.render.scenes`,
порядок = приоритет); хост может сменить сцену у показанного объекта.

```
<id>/<revision>/
  scene.json — профиль сцены (контракт: app/contracts/scene.schema.json)
```

Сейчас: `source-studio/v01`, `source-studio/v02` — студия Source (перенесены из пакета бутылки, #4).

- Масштаб: сцена задаёт свои единицы (`coordinates.worldScale`, единиц на метр) и масштабирует
  объект; объект сообщает свои единицы (`render.units`, `render.scale`). Сцена не перестраивается.
- Направление и чёткость тени задаёт свет сцены; тень требует их через `needsFromScene`.
- Сервер отдаёт папку по `/scenes/` (`SCENES_DIR`, по умолчанию `../scenes`).
- Документ — `docs/architecture/04-scene.md`.

Старая студия читает свои копии из `app/config/scenes/` — их не трогаем.
