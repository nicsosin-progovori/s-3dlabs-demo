# skus/ — продукты по SKU (бизнес-единица)

SKU — стабильный идентификатор продукта, **без версии**. Именно им общаются
все участники (URL, бар, плеер). Каждый SKU — папка `skus/<SKU>/sku.json`.
Позже это переедет в базу данных; формат файла = формат записи.

Два типа:

```jsonc
// simple — то, что можно показать. Ссылается на объект и скин.
{ "schemaVersion": 1, "sku": "44-MO9431-05", "type": "simple",
  "object": "bottle@v01",          // объект: id@revision (objects/<id>/<rev>/)
  "skin": "bottle-red@v01" }       // скин из пакета этого объекта

// configurable (parent) — группа вариантов, сам не рендерится.
{ "schemaVersion": 1, "sku": "44-MO9431-C", "type": "configurable",
  "variants": ["44-MO9431-03", "..."],
  "defaultVariant": "44-MO9431-03" }
```

- Объект указывается у **simple**: варианты могут отличаться не только скином
  (например, размером → другой объект).
- Плеер принимает только simple SKU. Parent → вариант разворачивает хост (бар).
- Если у соседних simple один и тот же `object`, плеер не перезагружает
  геометрию, а только меняет скин.
