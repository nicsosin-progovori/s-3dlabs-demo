# objects/ — данные объектов, ОТДЕЛЬНО от движка

Каждый объект — самодостаточный пакет `objects/<id>/<revision>/`, который движок
грузит по ключу `id@revision` и интерпретирует. Версия — в имени `<revision>`.

```
<id>/<revision>/
  manifest.json   — единая точка входа: что входит, пути + sha
  geometry/       — GLB (low/final + варианты) и их манифесты
  skins/          — материалы по цветам (skin.json)
  textures/       — PNG (имя = sha256)
  camera/         — каталог видов
  spec/           — спецификация продукта
```

Сцены в пакет объекта **не входят** (#4): они лежат отдельно в `scenes/<id>/<rev>/`.
Объект только называет их: `render.scenes = ["<id>@<rev>", …]` (порядок — приоритет),
и сообщает свои единицы: `render.units` (`metres` / `centimetres` / `millimetres`) и
`render.scale` (поправка, по умолчанию 1). Сцена масштабирует объект, сама не меняется.

Сейчас прототип: `objects/bottle/v01/` — КОПИЯ ассетов студии (`app/`), чтобы объект
был виден отдельно. Движок пока грузит из `app/`; следующий шаг — загрузчик по ID из
`objects/`, затем снятие хардкода и перевод студии сюда.
