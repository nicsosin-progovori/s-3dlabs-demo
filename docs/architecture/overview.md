## Что это
**S. 3DLABS** (`s-3dlabs`) — приложение для художественного рендеринга промо-товаров
с логотипом клиента. 3D-конфигуратор в браузере + серверный рендер идентичного
кадра в PNG. UI немецкий. Компания — SOURCE.

## Природа проекта (позиция владельца)
Проект — это **движок-потребитель**. В перспективе всё уедет наружу; сейчас это
демо с 1–10 проработанными объектами. Объекты — самодостаточные внешние пакеты
(свет, тени, текстуры, камеры, операции, пресеты под продукт), их структура и
хранение вынесены за пределы проекта; приложение лишь подтягивает данные.

## Стек
React 19 · @react-three/fiber 9 · @react-three/drei 10 · three.js 0.186 · Vite 8 ·
TypeScript 7 · Node ≥22. Серверный PNG — headless-Chromium через Playwright
(`render.html` / `BottleRenderWorker`). Деплой — Selectel (nginx + TLS), демо на
GitHub Pages.

## Точки входа
- `index.html` → `app/src/main.tsx` → `App` → единая студия SOURCE.
- `bottle.html` → `app/src/BottleApiPage.tsx` → страница одной бутылки + публичный API + PNG.
- `render.html` → `app/src/BottleRenderWorker.tsx` → невидимый worker для PNG.

## Слои кадра (термины)
1) модель/геометрия (LOD) · 2) скин/материал · 3) камера · 4) сцена ·
5) композиция · 6) брендинг/декор. Плюс рендерер — исполнитель контракта (не слой).
Каждый слой = версионированный контракт (`app/shared/*.mjs` + `.d.mts`) + рантайм-JSON,
читаемый одинаково клиентом и серверным PNG (sha256-parity).

## Фокус
