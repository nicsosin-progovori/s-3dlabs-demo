# shadows/ — набор теней, ОТДЕЛЬНО от движка

Движок тень не содержит: у него есть гнездо, в которое вставляется пакет тени.
Какую тень использовать и с какими параметрами — решает объект (`manifest.render.shadow`).

```
<id>/<revision>/
  shadow.json — контракт тени: параметры и их границы, ссылка на код + sha256
  shadow.js   — код тени (ES-модуль), three получает от движка
```

Сейчас: `soft-pcss/v01` — мягкая студийная тень (пол + фильтр на объекте).
Направление и чёткость тени задаёт свет сцены, не тень. Контракт — `docs/architecture/shadow.md`.
Сервер отдаёт папку по `/shadows/` (`SHADOWS_DIR`, по умолчанию `../shadows`).
